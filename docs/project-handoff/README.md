# Project Handoff Documents

This directory contains periodic handoff snapshots generated every 10 completed tasks.

## Purpose

Each handoff document provides a complete project status suitable for starting a new development session, transferring ownership, or onboarding a new contributor.

## Format

Files are named `handoff-NNN.md` where NNN is zero-padded (e.g., `handoff-010.md`).

## Contents (per handoff)

1. Project purpose
2. Current architecture
3. Implemented modules
4. Pending modules
5. Standards support status
6. GUI status
7. Build instructions
8. Test instructions
9. Active branches
10. Open issues
11. Known limitations
12. Recommended next 10 tasks
